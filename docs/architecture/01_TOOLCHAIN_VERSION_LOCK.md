Crowdbeats V2. No version numbers were copied from legacy reference documents.

"choose currently supported stable tool versions based on official manifests/tooling available
in the environment."

## Compatibility Evidence

### Flutter 3.47.1 + Dart 3.13.1

- Source: https://firebase.google.com/docs/functions/get-started#set_up_node.js

### Firebase CLI 15.28.1
- Always fetched via `npx -y firebase-tools@latest --version` as required by the
  `firebase-basics` skill instructions

## Upgrade Policy

1. Minor version bumps in dev tools (Prettier, ESLint): allowed between phases with no ADR
2. Flutter SDK minor bumps: allowed if `flutter upgrade` passes all existing tests
3. Next.js major/minor bumps: require type-check and build verification; log in this file
4. firebase-admin / firebase-functions: test against emulators before upgrading; log here
5. Node.js runtime: requires Firebase compatibility check; log here
